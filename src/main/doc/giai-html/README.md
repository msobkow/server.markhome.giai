These files are part of the Guided Intelligence Architecture Implementation Project GiAI v1.1.42 tool used to produce the data storage repositories
that GiAI uses to track and manage world-state information.  The tool produces Java JDK 25 compatible source code with attention to the restrictions
imposed by TeaVM to also produce support for JavaScript based clients.  In the future, there are plans to also produce source code for Rust, but only
the base directory for the Rust code exists so far. Before Rust can be produced, giai-core needs to be migrated and cross-compiled under Rust.
