Welcome to the Guided Intelligence Architecture Implementation - Project GiAI v1.1. This is where you will find the new home of Yorkton Code Fractal v3.1, which is now a subproject of the overall GiAI v1.1 project, but still accessible via the existing YCF links to the previously available implementation and website. Project GiAI builds on and leverages the YCF v3.1 technology to provide an enhancement specialization layer that provides for using YCF to produce code transformations of project business model specifications, build them, package them for deployment, and installing them to the development, project, and public web servers as appropriate to the release level of the current build.

The GNU Library General Public License 3.0 will apply to the giai-core code that is shared by all applications, in order to encourage people to contribute maintenance changes and enhancements to the public repositories and projects. The GNU General Public License 3.0 will apply to the Business Application Model and essential rule expansion support code that provides the functionality of the overall architecture. The Apache 2.0 License will apply to the code for the 3.1 Secure and IntNet schemas, so that they can be used and extended without restrictions to form application implementations according to your needs. The Knowledge Base is under Dual GPL 3.0, because I insist on having the development of the actual intelligence to be globally shared.
