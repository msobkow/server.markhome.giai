Welcome to the Guided Intelligence Architecture Implementation - Project GIAI v1.1. This is where you will find the new home of Yorkton Code Fractal v3.1, which is now a subproject of the overall GIAI v1.1 project, but still accessible via the existing YCF links to the previously available implementation and website. Project GIAI builds on and leverages the YCF v3.1 technology to provide an enhancement specialization layer that provides for using YCF to produce code transformations of project business model specifications, build them, package them for deployment, and installing them to the development, project, and public web servers as appropriate to the release level of the current build.
